# Original Group Analyses

This folder contains the original analyses performed using the initial three-group diagnostic classification:

* **Bipolar Disorder (BD)**
* **Major Depressive Disorder (MDD)**
* **Healthy Controls (HC)**

These analyses were conducted before the diagnostic groups were combined into a single **Mood Disorder** group for comparison with Healthy Controls.

The folder contains the original versions of the analyses organized by analytical area:

* **`sociodemographic/`** — Sociodemographic and clinical analyses.
* **`microbiota/`** — Microbiota processing, diversity analyses, and differential abundance analyses.
* **`machinelearning/`** — Machine learning analyses based on the original diagnostic grouping.

These files are retained to document the original analytical workflow and results and may differ from the revised analyses in the main repository folders.
